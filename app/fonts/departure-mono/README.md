# Departure Mono

Pixel-bitmap monospace, used for display titles, year markers, terminal card, and small pixel labels.

Source: <https://departuremono.com> (free).

Loaded by `app/layout.tsx` via `next/font/local` as `--font-departure-mono`. The token alias `--font-display` in `app/globals.css` references it, so Tailwind utilities like `font-display` resolve here.
